Binary search locates a target in a sorted list by repeatedly halving the remaining search interval. At each step, the algorithm compares the target with the middle element. If the target is smaller, only the lower half needs to be searched. If it is larger, only the upper half needs to be searched. The algorithm terminates when it finds the target or the interval becomes empty. For a list containing 1024 elements, at most eleven comparisons are needed by the usual inclusive-bound implementation. Binary search has logarithmic time complexity and an iterative implementation uses constant additional space. Linear search works on unsorted lists but can require a comparison with every element. A Python implementation can use integer lower and upper indices and compute the midpoint with integer division.
