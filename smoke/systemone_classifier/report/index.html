SYSTEM ONE / CLASSIFIER EXPERIMENT

Can a single-pass classifier
reproduce a reasoning reviewer?

Cloudflare Clef-Flash compared with frozen GPT-6.1 Sol judgments on 6,600 SFT and Dolci records. Four labels, one fixed rubric, complete inputs, and no tuning on the evaluation samples.

The decision: calibrate before filtering

The current four-class argmax decisions are too lenient to replace Sol. Clef labels 91.8% of SFT records and 81.8% of Dolci records “no defect found,” compared with Sol’s 45.5% and 20.7%. It identifies only 7.9% and 9.6% of Sol’s major-defect cases as major defects.

The few major-defect flags have relatively high agreement with Sol: precision is 80.5% for SFT and 87.7% for Dolci. But low recall leaves many material defects among the accepted records. Minor-defect and uncertainty decisions also agree poorly.

The probability scores show a more useful ranking signal. Major-defect AUROC is 0.723 on SFT and 0.769 on Dolci. This supports a separate calibration and held-out routing experiment, not deployment of a threshold chosen from this evaluation. These findings apply to this checkpoint and fixed rubric; they do not establish a general limit of System One models.

Measured execution cost

  • Model: Clef-Flash 9B, BF16 eager mode, one AMD MI325X GPU at a time on hissu, across two nodes after a restart. This is not an optimized inference benchmark.
  • Bulk run: 6,594 newly classified records in 74.0 minutes; 6 pilot records reused.
  • Observed throughput: 1.49 records/s and 15,042 input tokens/s.
  • Client concurrency: 4; pooling output tokens: zero. Initial server startup, model download, and pilot execution are excluded. Bulk wall time includes the Docker stop, failed requests, relocation, and restart. Extra server-side token validation and prefix caching are enabled; reported input tokens include cached prefix tokens.

The first server received a Docker stop signal after 4,067 accepted predictions; its initiator was not identified. Remaining records were resumed on another GPU with the same checkpoint, rubric, encoding, and precision. No records were discarded because of infrastructure failures. The resumed client used loopback HTTP instead of the login-node connection. This is a recovered run, not an uninterrupted timing benchmark.

No free-form reasoning was generated. The Sol runs used a remote service with unknown hardware and token-level compute cost; this experiment cannot establish a like-for-like FLOP, dollar, or energy saving. Compare agreement and measured local throughput before treating this as a replacement.

What to test next

Keep Sol as the reviewer for now. On a new calibration set, test routing by major-defect probability rather than using the four-class argmax as an automatic acceptance rule. Select a target for missed material defects, measure the resulting review coverage and workload reduction, then evaluate that fixed policy on an untouched set. Report uncertain and minor cases separately.

Human adjudication of a blinded disagreement sample would help distinguish Clef errors from Sol errors. Any revised prompt or trained decision head also needs a fresh held-out evaluation. No such adjudication, model training, threshold fitting, or post-hoc prompt optimization was performed here.

Reproduction and evidence

All artifacts live in smoke/systemone_classifier/. Model revision, input hashes, questions, runtime configuration, encoder override, per-record probabilities, exact token counts, and timing records are preserved. Source identities, Sol labels, and Sol explanations were excluded from classifier requests.

Primary metrics retain all four labels. Supplemental major-versus-nonmajor AUROC and average precision exclude Sol-uncertain cases and appear in metrics.json. Confidence intervals use 1,000 within-source bootstrap replicates and condition on the observed model labels; they omit systematic reviewer uncertainty.
